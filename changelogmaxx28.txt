R0CKY GAUGES - esp32-2.8-maxxecu changelog (จอ 2.8" MaxxECU)
=============================================================

0.8.1 (2026-11-25)
------------------

[เครื่องมือ]
- เพิ่มคำสั่ง Serial TOUCH? อ่านค่าทัชดิบ 5 วินาที (แรงกด ตำแหน่ง ขา IRQ) ใช้หาสาเหตุเวลาจอแตะไม่ไปหรืออ่านว่ากดค้าง

0.8.0 (2026-11-24)
------------------

[หน้า BUTTONS]
- เพิ่มหน้า BUTTONS กลับมาในจอ 2.8" (ปัดต่อจากหน้า DASH 3) เหลือ 4 ปุ่ม เรียง 2 ปุ่มต่อแถว (ปุ่มใหญ่ขึ้น กดง่ายขึ้น) ปุ่ม 5-8 ไม่แสดงบนจอ 2.8" (จอ 3.5" ยังเป็น 8 ปุ่มเหมือนเดิม)
- หน้า SYSTEM มีแถว BUTTONS (เปิด/ปิดการส่งปุ่ม) และ BUTTON SETUP กลับมา

0.7.1 (2026-11-23)
------------------

[หน้า BUTTONS]
- ปุ่มส่งเข้ากล่องแบบ Standard เปลี่ยนใหม่: ID 0x5F0 ปุ่มละไบต์ (ไบต์ 0 = ปุ่ม 1 ... ไบต์ 7 = ปุ่ม 8) ค่าในไบต์ = เลขปุ่ม (1-8) ตอนกด และ 0 ตอนปล่อย ทำให้ Current value ใน MTune ตรงกับเลขปุ่ม (เดิมเป็นบิตมาสก์ จึงได้ 1 2 4 8 16 32 64 128) ไม่มีตัวนับในไบต์ 1 แล้ว
- ต้องตั้ง MTune ใหม่: CAN input ปุ่มละ 1 ช่อง ไบต์ตามเลขปุ่ม unsigned 8 bit (โหมด Custom ไม่เปลี่ยน)

0.5.0 (2026-11-15)
------------------

[หน้าจอใหม่ ตามแบบ minimal]
- หน้าค่าแบบใหม่ 3 หน้า พื้นดำ ตัวเลขขาว ชื่อค่าและหน่วยสีเทา เส้นแบ่งบาง ไม่มีชื่อหน้าหรือโลโก้: หน้า 1 มี 4 ค่า (2 x 2) หน้า 2 มี 2 ค่า หน้า 3 มี 1 ค่า ตัวเลขใหญ่
- กดค้างที่ค่าไหนก็เลือกได้ว่าจะแสดงค่าอะไร แต่ละหน้าจำค่าของตัวเองแยกกัน ค่าที่เลือกไว้ในหน้า DASH เดิมยังอยู่ในหน้า 1
- ขนาดตัวเลขของแต่ละหน้าเลือกให้พอดีช่องเอง ค่ายาวหรือติดลบไม่ล้นช่อง รอบเครื่องใกล้รอบที่ตั้งเตือนตัวเลขเป็นสีแดง แถบเตือนยังขึ้นด้านล่างเหมือนเดิม
- ลำดับปัดหน้า: ค่า 1 > ค่า 2 > ค่า 3 > BUTTONS > CONNECTION > SYSTEM (6 หน้า)
- หน้า CONNECTION ใหม่ ใช้ต่อ Wi-Fi เพื่อดาวน์โหลดเฟิร์มแวร์เท่านั้น: แสดงสถานะ กด NETWORK เลือกเครือข่าย กด PASSWORD ใส่รหัส กด ACTION เพื่อเชื่อมต่อ ตัดการเชื่อมต่อ หรือยกเลิก
- หน้า SYSTEM เป็นรายการแถวเรียบ: ACCENT (สีเน้น) BACKGROUND (สีพื้น) CARDS (สีการ์ดหน้าค่า) SCREEN INVERT FIRMWARE (บอกรุ่น หรือ Update เมื่อมีรุ่นใหม่ กดเข้าไปดาวน์โหลด/ติดตั้ง) DEMO และ DEVICE (Restart กดสองครั้ง) รายการยาวกว่าจอ ปัดขึ้นลงเพื่อเลื่อน
- หน้า ALERT LIMIT และ FIRMWARE ย้ายไปเปิดจาก SYSTEM แตะ < SYSTEM มุมขวาบน หรือปัดซ้าย/ขวา เพื่อกลับ
- ปุ่ม DEMO ย้ายจากหน้าการเชื่อมต่อไปอยู่ในหน้า SYSTEM
- ไม่มีจุดบอกหน้า (ไข่ปลา) ทุกหน้า
- ตอนตัวเลขเปลี่ยน จอวาดใหม่เฉพาะส่วนตัวเลขและหน่วยของช่องนั้น (ไม่วาดชื่อค่าและช่องอื่นซ้ำ) เร็วขึ้นมาก
- แยกงาน CAN ออกเป็น task ของตัวเองบนอีก core: การอ่านค่าจาก MaxxECU และการส่งเฟรมปุ่มทำงานตลอดเวลา ไม่ต้องรอการวาดหน้าจอหรือการแตะจอ ค่าจึงไม่หลุดเป็น -- เพราะหน้าจอวาดช้า และจอ/การปัดไม่รวนตอนมีข้อมูล CAN วิ่งเยอะ หน้า BUTTONS วาดใหม่ทั้งหน้าไม่เกินประมาณ 3 ครั้งต่อวินาที
- แก้ค่ากระพริบเป็น -- เป็นช่วง ๆ: จอส่งเฟรมปุ่มเฉพาะตอนที่มีปุ่มเปิดอยู่ (และต่ออีก 1 วินาทีหลังปิด) ไม่ได้ส่งตลอดเวลาแล้ว ถ้าเฟรมที่จอส่งเจอ error บนสาย CAN จะหยุดส่ง 5 วินาที ไม่ให้ตัวรับ CAN ของจอหลุด (bus-off) จนค่าหายทั้งหน้า และกู้ตัวรับ CAN คืนเร็วขึ้น (เช็คทุก 0.1 วินาที) คำสั่ง CAN? บอก txErr และจำนวนครั้งที่หยุดส่งด้วย
- แก้ค่าบนจอขึ้น -- บ่อยเมื่อสาย CAN มีข้อมูลอื่นของรถวิ่งอยู่ด้วย: จอรับเฉพาะ ID 0x500-0x5FF อีกครั้ง (ค่าจาก MaxxECU และสถานะปุ่ม) ข้อมูลอื่นบนสายไม่ไปเบียดคิวรับแล้ว และคิวรับใหญ่ขึ้น (128 เฟรม) จะรับทุก ID เฉพาะเมื่อตั้ง STATUS ID ของปุ่มไว้นอกช่วงนี้
- ปัดเปลี่ยนหน้าลื่นขึ้น: หน้าค่าวาดตัวเลขใหม่ไม่เกินประมาณ 6-7 ครั้งต่อวินาที และหยุดวาดระหว่างที่นิ้วแตะจอ (เดิมวาดใหม่ทุกครั้งที่มีข้อมูลเข้า ทำให้จอตอบสนองการปัดช้า)
- ชื่อค่าในหน้าค่าทั้ง 3 หน้า (RPM, SPEED, COOLANT, BOOST ...) ใหญ่ขึ้น (26 px) เป็นตัวหนา และเว้นระยะระหว่างตัวอักษร อ่านง่ายขึ้นบนจอ 2.8"
- หน้าค่าลดจำนวนค่าให้ตัวใหญ่ขึ้น: หน้า 1 เหลือ 4 ค่า หน้า 2 เหลือ 2 ค่า หน้า 3 เหลือ 1 ค่า (ตัวเลขใหญ่สุด 75 px เมื่อใส่ได้) ค่าที่เลือกไว้ในช่องแรก ๆ ของแต่ละหน้ายังอยู่ หน่วยเป็นตัวเล็กสีเทาเหมือนเดิม
- ช่องค่าในหน้าค่าทั้ง 3 หน้ายืดลงมาใช้พื้นที่ด้านล่างที่เคยเป็นจุดบอกหน้า
- เพิ่มแถว CARDS ในหน้า SYSTEM เลือกให้หน้าค่าแบ่งเป็นการ์ดแยกแต่ละค่าพร้อมสีพื้นการ์ด: Off (แบบเรียบมีเส้นแบ่ง ค่าเริ่มต้น), Dark, Grey, Red, Blue, Green, Orange ตัวหนังสือเปลี่ยนเป็นขาวหรือดำเองให้อ่านง่าย บอร์ดจำค่าไว้ (ปุ่มที่ปิดอยู่ในหน้า BUTTONS ใช้สีการ์ดเดียวกัน)
- เอาหน้า BOOST & PEAK ออก (ดูบูสต์ได้ที่หน้าค่า กดค้างที่ช่องแล้วเลือก BOOST)
- หน้า ALERT LIMIT ออกแบบใหม่: รายการเรียบ แบ่ง 2 หน้าย่อย หน้าละ 3 ค่า (Engine RPM, Speed, Coolant / Throttle, MAP, Battery low) กด < > เปลี่ยนหน้าย่อย แต่ละแถวบอกขีดจำกัดพร้อมเครื่องหมาย (> เตือนเมื่อเกิน, < เตือนเมื่อต่ำกว่า สำหรับแบตเตอรี่) และมีสวิตช์เปิด/ปิดทางขวา สีส้มเมื่อเปิด สีเทาเมื่อปิด
- ปิดสวิตช์แล้วการเตือนค่านั้นหยุดจริง เปิดใหม่ใช้ขีดจำกัดเดิมที่จำไว้ บอร์ดจำทั้งค่าและสถานะเปิด/ปิด
- แตะที่แถว (ไม่ใช่สวิตช์) เข้าหน้าแก้ค่า: ตัวเลขใหญ่ ปุ่ม - / + และ SAVE กด < BACK ยกเลิกค่าที่ยังไม่ SAVE แก้ค่าของการเตือนที่ปิดอยู่ได้โดยไม่เปิดเตือนเอง MAP ยังเป็น kPa เหมือนเดิม
- เอา SPEED CAL ออก (ความเร็วมาจากกล่อง MaxxECU โดยตรง ไม่ได้ใช้ค่าปรับเทียบนี้)
- หน้า FIRMWARE ออกแบบใหม่: บอกรุ่นบอร์ด (OBD2 / MaxxECU กับขนาดจอ) และสถานะ Wi-Fi ถ้ายังไม่ต่อ Wi-Fi แตะเพื่อไปหน้า CONNECTION มี 3 แถว Installed / On SD card / Available online แสดงรุ่นจริง หรือบอกว่าไม่มีการ์ด ไม่มีไฟล์ ไฟล์ใช้ไม่ได้ ไม่มี Wi-Fi หรือติดต่อเซิร์ฟเวอร์ไม่ได้
- ปุ่ม DOWNLOAD (โหลดไฟล์ลง SD) และ INSTALL (ติดตั้งจากไฟล์บน SD) เป็นสีเทาและกดไม่ได้เมื่อทำไม่ได้ ติดตั้งจาก SD ได้แม้ไม่มี Wi-Fi ดาวน์โหลดเสร็จแล้วไม่ติดตั้งเอง
- กด INSTALL แล้วขึ้นหน้ายืนยัน บอกรุ่นปัจจุบัน > รุ่นที่จะติดตั้ง (เตือนถ้าเป็นรุ่นเก่ากว่า) มีปุ่ม CANCEL และ INSTALL NOW กด CANCEL หรือ BACK จะไม่เขียนเฟิร์มแวร์ (แทนการกด FLASH สองครั้งแบบเดิม)
- หน้าระหว่าง Downloading / Installing ใช้ตัวเลขเปอร์เซ็นต์ใหญ่และแถบเส้นเดียวจากความคืบหน้าจริง ไม่ขึ้น 100% ก่อนเสร็จจริง ถ้าเซิร์ฟเวอร์ไม่บอกขนาดไฟล์จะไม่แสดงเปอร์เซ็นต์ ถ้าล้มเหลวกลับมาหน้า FIRMWARE พร้อมบอกสาเหตุ
- สวิตช์กลับสีจอ (SCREEN INVERT) ย้ายมาเป็นแถวในหน้า SYSTEM

[ปุ่มกดสั่งกล่อง MaxxECU]
- เพิ่มหน้า BUTTONS ต่อจากหน้าค่า 3 (ลำดับปัดหน้า: ค่า 1 > ค่า 2 > ค่า 3 > BUTTONS > CONNECTION > SYSTEM รวม 6 หน้า) มี 8 ปุ่ม กดแล้วสลับ ON/OFF ปุ่มที่เปิดเป็นสีเน้น
- จอส่งสถานะปุ่มเข้ากล่องทางสาย CAN: ID 0x5F0 ไบต์ 0 = ปุ่ม 1-8 (บิต 0 = ปุ่ม 1) ไบต์ 1 = ตัวนับ ส่งทุก 50 ms เฉพาะตอนที่มีข้อมูลจากกล่องเข้ามาและมีปุ่มเปิดอยู่ มุมขวาล่างบอกว่ากำลังส่งอยู่หรือไม่ (หน้านี้ไม่มีชื่อหน้า ปุ่มใช้พื้นที่เต็มจอ)
- ตั้งใน MTune: CAN-bus > User CAN inputs รับ ID 0x5F0 ไบต์ 0 แบบ bit mask (0x01 = ปุ่ม 1 ... 0x80 = ปุ่ม 8) แล้วผูกกับฟังก์ชันที่ต้องการ ควรตั้งค่าเริ่มต้น/หมดเวลาเป็น OFF เพราะถ้าจอดับเฟรมจะหยุดส่ง
- เปิดเครื่องมาทุกปุ่มเป็น OFF เสมอ
- เพิ่ม SYSTEM > BUTTON SETUP ตั้งปุ่มได้ 2 แบบ: Standard (ตั้งใหม่ ใช้ ID 0x5F0 ไบต์ 0 ปุ่มละบิต) หรือ Custom (กล่องที่ตั้ง CAN input ไว้แล้ว) กำหนดทีละปุ่มว่าส่งไป ID / ไบต์ / บิตไหน ตัวแก้เลข ID เป็นฐานสิบหก 3 หลัก แตะ + / - ทีละหลัก ปุ่มที่ใช้ ID เดียวกันรวมส่งในเฟรมเดียว
- ปุ่มแสดงสถานะจริงจากกล่องได้: ตั้ง STATUS ID / ไบต์ / บิต (ค่าเริ่มต้น ID 0x570 ไบต์ละปุ่ม ตั้งใน MTune เป็น CAN output) ปุ่มเติมสีเมื่อกล่องทำงานจริง ขอบสีพร้อมคำว่า WAIT เมื่อสั่งเปิดแล้วแต่กล่องยังไม่ทำงาน ECU ON เมื่อกล่องเปิดเองจากที่อื่น ถ้าไม่มีสถานะเข้ามาจะแสดงตามที่จอสั่งเหมือนเดิม
- Serial เพิ่ม BTNMAP=1,7B,0,0 (ปุ่ม, ID, ไบต์, บิต), BTNSTAT=1,570,0,ANY (หรือ OFF), BTNSTD (กลับแบบ Standard) จอรับเฟรมจากทุก ID แล้ว (เดิมรับแค่ 0x500-0x57F) เพื่อให้สถานะจาก ID ใดก็ได้เข้ามาได้
- ตั้งผ่าน Serial Monitor: BTN? ดูสถานะ, BTNNAME=1,LAUNCH ตั้งชื่อปุ่ม, BTNMODE=1,PULSE ให้ปุ่มเปิดแค่ 0.5 วินาทีแล้วดับเอง (TOGGLE = สลับเปิด/ปิด), BTNID=5F0 เปลี่ยน ID หรือ BTNID=OFF หยุดส่ง (บอร์ดจำค่าไว้)

0.4.0 (2026-11-15)
------------------

[วินิจฉัย]
- เพิ่มคำสั่ง CANHOLD ใน Serial Monitor ให้จอดึงขา TX ของ CAN ลง LOW ค้าง 10 วินาที (แล้ว HIGH 5 วินาที) ใช้มิเตอร์วัดที่ขา D, R และ CAN H - CAN L ของบอร์ดแปลงได้ว่าสัญญาณจากจอไปถึงชิปจริงหรือไม่ พร้อมตรวจสาย RX ด้วย pull-up/pull-down ว่าต่ออยู่หรือลอย

0.3.3 (2026-11-13)
------------------

------------------

[MaxxECU]
- เฟิร์มแวร์ใหม่สำหรับรถที่ใช้กล่อง MaxxECU (แยกจากรุ่น OBD2 ที่ใช้ ELM327) แตกมาจากจอ 2.8" OBD2 รุ่น 1.18.0 หน้าตาเหมือนเดิมทุกหน้า
- รับค่าจากสาย CAN ของ MaxxECU โดยตรงที่ 500 kbit/s ไม่ต้องใช้ ELM327 ต่อผ่านตัวแปลง CAN 3.3 V (SN65HVD230) ที่ช่อง CN1: IO27 = TX, IO22 = RX ใน MTune ต้องเปิด CAN-bus > Default CAN output เป็น MaxxECU Default 1.3 (หรือ 1.2 แต่จะไม่มีค่าน้ำมันเครื่อง แรงดันเชื้อเพลิง อุณหภูมิเกียร์ และ AFR CMD)
- ค่าบนการ์ด: RPM, SPEED, MAP, THROTTLE, COOLANT, BATT, TIMING, AFR (จาก lambda x 14.7), AFR CMD (lambda target), INJ DUTY, OIL TEMP, FUEL PRS, INTAKE, STFT (lambda correction A), BARO, TRAN TEMP ค่าที่ MaxxECU ไม่ส่ง (LOAD, RAIL PRS, MAF, FUEL LVL, LTFT, AMBIENT, CAT TEMP, PEDAL) ขึ้น --
- BOOST คิดจาก MAP ลบ baro ที่ MaxxECU ส่งมา (เดิมใช้ค่าคงที่ 101 kPa)
- หัวจอขึ้น LINK เมื่อมีข้อมูล CAN เข้ามา หยุดรับเกิน 0.5 วินาทีถือว่าหลุด ตัวเลขเป็น --
- หน้า TROUBLE CODES: READ แสดงจำนวน error ของ MaxxECU ส่วนรายละเอียดและการล้างให้ทำใน MTune
- หน้า DEVICES ใช้ต่อ WiFi เพื่ออัพเดตเฟิร์มแวร์อย่างเดียว อัพเดตใช้ไฟล์ maxx28.bin แยกจากรุ่น OBD2 (dash.bin) จอ MaxxECU จะไม่โหลดเฟิร์มแวร์ OBD2 มาลงเอง
