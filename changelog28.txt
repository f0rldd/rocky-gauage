1.20.0 (2026-11-15)
------------------

[หน้าจอใหม่ ตามแบบ minimal]
- หน้าค่าแบบใหม่ 3 หน้า พื้นดำ ตัวเลขขาว ชื่อค่าและหน่วยสีเทา เส้นแบ่งบาง ไม่มีชื่อหน้าหรือโลโก้: หน้า 1 มี 4 ค่า (2 x 2) หน้า 2 มี 2 ค่า หน้า 3 มี 1 ค่า ตัวเลขใหญ่
- กดค้างที่ค่าไหนก็เลือกได้ว่าจะแสดงค่าอะไร แต่ละหน้าจำค่าของตัวเองแยกกัน ค่าที่เลือกไว้ในหน้า DASH เดิมยังอยู่ในหน้า 1
- ขนาดตัวเลขของแต่ละหน้าเลือกให้พอดีช่องเอง ค่ายาวหรือติดลบไม่ล้นช่อง รอบเครื่องใกล้รอบที่ตั้งเตือนตัวเลขเป็นสีแดง แถบเตือนยังขึ้นด้านล่างเหมือนเดิม
- ลำดับปัดหน้า: ค่า 1 > ค่า 2 > ค่า 3 > DEVICE > CONNECTION > SYSTEM (6 หน้า)
- หน้า DEVICE ใหม่สำหรับ ELM327: แถว Direct CAN (ต่อสาย CAN ตรง) และปุ่ม SCAN รายชื่อ ELM327 Bluetooth พร้อมที่อยู่ ตัวที่ต่ออยู่มีแถบสีและคำว่า Connected กด Disconnect ทางขวาเพื่อตัด ตัวอื่นกด Connect ได้เลย (ELM327 แบบ Wi-Fi ที่ต่ออยู่ก็แสดงที่นี่)
- หน้า CONNECTION ใหม่ ใช้ต่อ Wi-Fi เพื่อดาวน์โหลดเฟิร์มแวร์เท่านั้น: แสดงสถานะ กด NETWORK เลือกเครือข่าย กด PASSWORD ใส่รหัส กด ACTION เพื่อเชื่อมต่อ ตัดการเชื่อมต่อ หรือยกเลิก
- ถ้าต่อ ELM327 ทาง Bluetooth อยู่ หน้า CONNECTION จะเตือนว่าการต่อ Wi-Fi จะตัดลิงก์ Bluetooth
- หน้า SYSTEM เป็นรายการแถวเรียบ: ACCENT (สีเน้น) BACKGROUND (สีพื้น) CARDS (สีการ์ดหน้าค่า) SCREEN INVERT FIRMWARE (บอกรุ่น หรือ Update เมื่อมีรุ่นใหม่ กดเข้าไปดาวน์โหลด/ติดตั้ง) DEMO และ DEVICE (Restart กดสองครั้ง) รายการยาวกว่าจอ ปัดขึ้นลงเพื่อเลื่อน
- หน้า ALERT LIMIT, TROUBLE CODES และ FIRMWARE ย้ายไปเปิดจาก SYSTEM แตะ < SYSTEM มุมขวาบน หรือปัดซ้าย/ขวา เพื่อกลับ
- ปุ่ม DEMO ย้ายจากหน้าการเชื่อมต่อไปอยู่ในหน้า SYSTEM
- ไม่มีจุดบอกหน้า (ไข่ปลา) ทุกหน้า
- ตอนตัวเลขเปลี่ยน จอวาดใหม่เฉพาะส่วนตัวเลขและหน่วยของช่องนั้น (ไม่วาดชื่อค่าและช่องอื่นซ้ำ) เร็วขึ้นมาก
- ปัดเปลี่ยนหน้าลื่นขึ้น: หน้าค่าวาดตัวเลขใหม่ไม่เกินประมาณ 6-7 ครั้งต่อวินาที และหยุดวาดระหว่างที่นิ้วแตะจอ (เดิมวาดใหม่ทุกครั้งที่มีข้อมูลเข้า ทำให้จอตอบสนองการปัดช้า)
- ชื่อค่าในหน้าค่าทั้ง 3 หน้า (RPM, SPEED, COOLANT, BOOST ...) ใหญ่ขึ้น (26 px) เป็นตัวหนา และเว้นระยะระหว่างตัวอักษร อ่านง่ายขึ้นบนจอ 2.8"
- หน้าค่าลดจำนวนค่าให้ตัวใหญ่ขึ้น: หน้า 1 เหลือ 4 ค่า หน้า 2 เหลือ 2 ค่า หน้า 3 เหลือ 1 ค่า (ตัวเลขใหญ่สุด 75 px เมื่อใส่ได้) ค่าที่เลือกไว้ในช่องแรก ๆ ของแต่ละหน้ายังอยู่ หน่วยเป็นตัวเล็กสีเทาเหมือนเดิม
- ช่องค่าในหน้าค่าทั้ง 3 หน้ายืดลงมาใช้พื้นที่ด้านล่างที่เคยเป็นจุดบอกหน้า
- เพิ่มแถว CARDS ในหน้า SYSTEM เลือกให้หน้าค่าแบ่งเป็นการ์ดแยกแต่ละค่าพร้อมสีพื้นการ์ด: Off (แบบเรียบมีเส้นแบ่ง ค่าเริ่มต้น), Dark, Grey, Red, Blue, Green, Orange ตัวหนังสือเปลี่ยนเป็นขาวหรือดำเองให้อ่านง่าย บอร์ดจำค่าไว้
- เอาหน้า BOOST & PEAK ออก (ดูบูสต์ได้ที่หน้าค่า กดค้างที่ช่องแล้วเลือก BOOST)
- หน้า ALERT LIMIT ออกแบบใหม่: รายการเรียบ แบ่ง 2 หน้าย่อย หน้าละ 3 ค่า (Engine RPM, Speed, Coolant / Throttle, MAP, Battery low) กด < > เปลี่ยนหน้าย่อย แต่ละแถวบอกขีดจำกัดพร้อมเครื่องหมาย (> เตือนเมื่อเกิน, < เตือนเมื่อต่ำกว่า สำหรับแบตเตอรี่) และมีสวิตช์เปิด/ปิดทางขวา สีส้มเมื่อเปิด สีเทาเมื่อปิด
- ปิดสวิตช์แล้วการเตือนค่านั้นหยุดจริง เปิดใหม่ใช้ขีดจำกัดเดิมที่จำไว้ บอร์ดจำทั้งค่าและสถานะเปิด/ปิด
- แตะที่แถว (ไม่ใช่สวิตช์) เข้าหน้าแก้ค่า: ตัวเลขใหญ่ ปุ่ม - / + และ SAVE กด < BACK ยกเลิกค่าที่ยังไม่ SAVE แก้ค่าของการเตือนที่ปิดอยู่ได้โดยไม่เปิดเตือนเอง MAP ยังเป็น kPa เหมือนเดิม
- SPEED CAL ย้ายออกจากหน้าเตือนไปเป็นแถวใน SYSTEM แตะแล้วปรับได้ทีละ 0.5 % (0 ถึง 10 %) ค่าเดิมยังอยู่
- หน้า FIRMWARE ออกแบบใหม่: บอกรุ่นบอร์ด (OBD2 / MaxxECU กับขนาดจอ) และสถานะ Wi-Fi ถ้ายังไม่ต่อ Wi-Fi แตะเพื่อไปหน้า CONNECTION มี 3 แถว Installed / On SD card / Available online แสดงรุ่นจริง หรือบอกว่าไม่มีการ์ด ไม่มีไฟล์ ไฟล์ใช้ไม่ได้ ไม่มี Wi-Fi หรือติดต่อเซิร์ฟเวอร์ไม่ได้
- ปุ่ม DOWNLOAD (โหลดไฟล์ลง SD) และ INSTALL (ติดตั้งจากไฟล์บน SD) เป็นสีเทาและกดไม่ได้เมื่อทำไม่ได้ ติดตั้งจาก SD ได้แม้ไม่มี Wi-Fi ดาวน์โหลดเสร็จแล้วไม่ติดตั้งเอง
- กด INSTALL แล้วขึ้นหน้ายืนยัน บอกรุ่นปัจจุบัน > รุ่นที่จะติดตั้ง (เตือนถ้าเป็นรุ่นเก่ากว่า) มีปุ่ม CANCEL และ INSTALL NOW กด CANCEL หรือ BACK จะไม่เขียนเฟิร์มแวร์ (แทนการกด FLASH สองครั้งแบบเดิม)
- หน้าระหว่าง Downloading / Installing ใช้ตัวเลขเปอร์เซ็นต์ใหญ่และแถบเส้นเดียวจากความคืบหน้าจริง ไม่ขึ้น 100% ก่อนเสร็จจริง ถ้าเซิร์ฟเวอร์ไม่บอกขนาดไฟล์จะไม่แสดงเปอร์เซ็นต์ ถ้าล้มเหลวกลับมาหน้า FIRMWARE พร้อมบอกสาเหตุ
- สวิตช์กลับสีจอ (SCREEN INVERT) ย้ายมาเป็นแถวในหน้า SYSTEM

[ต่อ CAN ตรง (ไม่ใช้ ELM327)]
- หน้า DEVICE มีแถว Direct CAN อยู่บนสุดเสมอ กด Connect แล้วจออ่านค่าจากสาย CAN ของปลั๊ก OBD2 โดยตรงผ่านบอร์ดแปลง CAN (SN65HVD230) ไม่ต้องใช้ ELM327 ส่วน ELM327 แบบ Bluetooth / Wi-Fi ยังใช้ได้เหมือนเดิม เลือกได้ในหน้าเดียวกัน บอร์ดจำว่าใช้แบบไหนและต่อเองตอนเปิดเครื่อง
- การต่อสาย: IO27 (TX) และ IO22 (RX) ที่ช่อง CN1 -> ขา D/TXD และ R/RXD ของบอร์ดแปลง, CAN H / CAN L -> ขา 6 / 14 ของปลั๊ก OBD2, GND ร่วมกัน (เหมือนรุ่น MaxxECU)
- หาความเร็วบัสเอง (500k / 250k, ID 11 / 29 บิต) โดยฟังอย่างเดียวก่อน จะไม่ส่งข้อมูลออกไปที่ความเร็วผิด จึงไม่รบกวนบัสของรถ
- ค่าทุกอย่างอ่านเหมือนตอนใช้ ELM327: ค่าบนหน้าค่า, PID ที่รถรองรับ, TROUBLE CODES (อ่าน/ลบ) และ log
- พิมพ์ CAN? ใน Serial Monitor ดูสถานะลิงก์ CAN

1.19.0 (2026-11-13)
------------------

[หน้าจอ Racing Premium]
- ออกแบบหน้า DASH ใหม่เป็นพื้นเข้ม สีเน้นส้ม ช่องค่าหลักเด่นและช่องรองกระชับ พร้อมหน่วยของค่า
- เพิ่มแถบ RPM ด้านบน แสดงรอบเครื่องตลอดแม้เปลี่ยนค่าในช่อง และเปลี่ยนสีใกล้รอบที่ตั้งเตือน
- แสดงสถานะ LIVE, OFFLINE หรือ DEMO บนหน้าหลัก พร้อมคำแนะนำกดค้างเปลี่ยนค่าและปัดเข้าเมนู
- ปรับสีเน้นและปุ่มหลักของหน้าตั้งค่าให้เข้าชุดกับหน้าปัดใหม่เมื่อเลือกธีม BLACK
- จัดพื้นที่แถบแจ้งเตือนแยกด้านล่าง ไม่ทับตัวเลขของช่องค่า
- ปรับหน้ารองให้เข้าชุด Racing Premium: แถบหัวหน้า ปุ่ม หน้า Peak การเชื่อมต่อ ตั้งค่าเตือน และ System
- หน้าเลือกค่าใช้ปุ่มใหญ่ขึ้น 18 ค่าต่อหน้า พร้อมกรอบแสดงค่าที่เลือก และแป้นพิมพ์ WiFi ใช้สีตามธีม
- หน้าดาวน์โหลดและแฟลชใช้แถบความคืบหน้าแบบ Racing Premium เช่นเดียวกับจอใหญ่
- ปรับหน้ารหัสปัญหาให้แยกสถานะพร้อมอ่าน ไม่พบรหัส และรายการรหัสชัดขึ้น

1.18.0 (2026-11-11)
------------------

[หน้าจอ]
- จอ 2.8" เหลือ 6 หน้า เรียง: DASH > BOOST & PEAK > DEVICES > ALERT LIMITS > TROUBLE CODES > SYSTEM (ลำดับเดียวกับจอ 3.5") เอาหน้า LOG ออก (กราฟบนจอเล็กอ่านยาก) แต่ยังบันทึก log ลง SD เหมือนเดิม ดูไฟล์ด้วย R0CKY-LogViewer บนคอม จุดบอกหน้าที่หัวจอเหลือ 6 จุด
- แจ้งเตือนเกินค่าที่ตั้ง (ALERT LIMITS) เปลี่ยนจากจอแดงเต็มจอกะพริบ เป็นแถบสีเหลืองอำพันโปร่งแสงพาดด้านล่างหน้า DASH ตัวหนังสือสีเข้ม เช่น ENGINE RPM OVERREV, COOLANT TEMP HIGH, BATTERY VOLTAGE LOW การ์ดยังมองเห็นอยู่ข้างหลัง ไฟจอไม่กะพริบแล้ว
- เลือกสีการ์ดเองได้ในหน้า SYSTEM แถว Cards: แตะสีที่ต้องการจาก 5 สี (ดำ แบบเดิม, ขาว, แดง, น้ำเงิน, เหลือง) ใช้กับการ์ดทุกหน้า (DASH, BOOST & PEAK, DEVICES, ALERT LIMITS, LOG, TROUBLE CODES, SYSTEM) ตัวหนังสือบนการ์ดเปลี่ยนเป็นดำบนสีอ่อน ขาวบนสีเข้มเอง บอร์ดจำค่าไว้ (RPM ใกล้รอบเตือนบนการ์ดสีแดงเป็นสีเหลืองแทน)
- เลือกสีพื้นหลังทั้งจอได้ในหน้า SYSTEM แถว Background (5 สีเหมือนการ์ด) ใช้กับทุกหน้า ตัวหนังสือบนพื้นหลัง (หัวข้อหน้า ข้อความสถานะ) เปลี่ยนเป็นดำบนสีอ่อน ขาวบนสีเข้มเอง ถ้าการ์ดกับพื้นหลังเป็นสีเดียวกัน การ์ดจะมีเส้นขอบให้เห็น หน้า SYSTEM จัดให้ชิดขึ้นเพื่อให้มีที่สำหรับแถวใหม่
- ไม่มีสีส้มแล้ว: สีเน้น (เส้นใต้หัวข้อ จุดบอกหน้า ตัวเลขใน ALERT LIMITS เส้นกราฟ แถบบูสต์ ป้าย BLE ช่องที่เลือก กรอบสีที่เลือก ปุ่มบนแป้นพิมพ์ WiFi แถบความคืบหน้า) เป็นสีเดียวกับการ์ดที่เลือก การ์ดดำ = สีขาว ถ้าสีเน้นตรงกับพื้นหลังจะใช้สีตัวหนังสือแทน
- สีให้เลือกเป็นสีล้วนไม่มีสีเทาปน: แดง (255,0,0) น้ำเงิน (0,0,255) เหลือง (255,255,0) ตัวหนังสือบนแดง/น้ำเงินเป็นขาว บนเหลือง/ขาวเป็นดำ
- ปุ่มหลัก (SCAN, READ, FLASH, ปุ่มซูมกราฟ, OK ของหน้ากรอกรหัส WiFi) ไม่เป็นสีส้มแล้ว ใช้สีเดียวกับการ์ดที่เลือกในหน้า SYSTEM ถ้าการ์ดสีดำ ปุ่มเป็นสีขาว ตัวหนังสือดำ
- หน้า DASH ไม่มีกรอบการ์ดแล้ว เหลือแค่เส้นแบ่งระหว่างช่อง (แบบตาราง ไม่มีขอบนอก) เส้นเป็นสีการ์ดที่เลือก (การ์ดดำ = เส้นเทา) ตัวหนังสือวางบนพื้นหลังโดยตรง
- หน้า DASH: ชื่อค่า (SPEED, RPM ฯลฯ) อยู่มุมซ้ายบนของแต่ละช่อง มีเส้นสั้นสีเดียวกันขีดใต้ เหมือนหัวข้อของทุกหน้า (พื้นหลังดำ = สีประจำแต่ละค่า, พื้นหลังสีอื่น = สีเดียวกับการ์ด)
- จอ 2.8" หน้า DASH: ตัวเลขเลื่อนลงมาเล็กน้อย ห่างจากชื่อค่ามากขึ้น อยู่กลางพื้นที่ใต้ชื่อพอดี

- กดค้างที่การ์ดบนหน้า DASH ประมาณครึ่งวินาที เพื่อเลือกว่าการ์ดนั้นแสดงค่าอะไร (มีให้เลือก 25 ค่า แตะ CANCEL เพื่อออก) บอร์ดจำค่าที่เลือกไว้ ปิดเปิดใหม่ก็ยังอยู่
- ค่าใหม่ที่เลือกได้ (PID มาตรฐาน): LOAD (โหลดเครื่อง), OIL TEMP (อุณหภูมิน้ำมันเครื่อง), FUEL PRS (แรงดันเชื้อเพลิง 010A), RAIL PRS (แรงดันรางหัวฉีด 0123 หน่วย MPa), INTAKE (อุณหภูมิอากาศเข้า), MAF, FUEL LVL (น้ำมันในถัง), STFT / LTFT (fuel trim), BARO, AMBIENT (อุณหภูมินอกรถ), CAT TEMP (อุณหภูมิแคต), PEDAL (คันเร่ง), TRAN TEMP (อุณหภูมิเกียร์ 01B4 ที่ Torque เรียก Method 2: รถส่วนใหญ่ไม่ตอบ เพราะค่าเกียร์ออโต้/CVT จริงอยู่ในกล่องเกียร์ ต้องใช้คำสั่งเฉพาะรุ่น) และ AFR CMD, INJ DUTY

1.8.1 (2026-10-19)
------------------

[SD card]
- ถ้าการ์ดเมานต์ไม่ติดตอนเปิดเครื่อง บอร์ดจะลองใหม่ที่ความเร็วต่ำลงเอง (4 MHz แล้ว 1 MHz) และพิมพ์ผลออก Serial Monitor

[WiFi]
- ต่อ WiFi ลองสูงสุด 3 รอบ (รอบแรกล็อกตาม BSSID ที่จำไว้ รอบหลังหาจากชื่อ) แก้อาการ hotspot หรือเราเตอร์ที่เปลี่ยน BSSID แล้วต่อไม่ติด และจำ BSSID ใหม่ให้อัตโนมัติ
- หา ELM ผ่าน TCP รอนานขึ้น (1.5 วินาที) และถ้าเคยต่อกล่องนี้ได้แล้วจะลองซ้ำอีกรอบ ลดอาการต่อติดบ้างไม่ติดบ้าง
- ต่อ WiFi บ้านหรือ hotspot ค้างไว้ (เครือข่ายที่ไม่มี ELM) ตอนนี้ขึ้นเป็นแถวแรกในหน้า DEVICES พร้อมขอบเขียวเหมือนอุปกรณ์ OBD ที่เชื่อมต่ออยู่
- ต่อ WiFi ไม่สำเร็จ บอร์ดพิมพ์สาเหตุ (รหัสสถานะ) ออก Serial Monitor เพื่อใช้ไล่หาว่าหา SSID ไม่เจอหรือรหัสผ่านผิด

- บอร์ดเซ็นรับรองข้อมูลทุก 10 วินาที เซ็นอยู่เบื้องหลัง จอและการอ่านค่าไม่สะดุด ถ้าไฟดับ ข้อมูลช่วงท้ายที่ยังไม่ได้เซ็น (ไม่เกิน 10 วินาที) จะขึ้นว่าไม่มีลายเซ็น
- บอร์ดที่ใส่กุญแจแบบเก่าไว้ต้องใส่กุญแจใหม่ด้วย R0CKY-ShopTool ก่อน ไม่อย่างนั้นไฟล์ log จะไม่มีลายเซ็น
- หน้า LOG บนจอยังเปิดไฟล์ log แบบเก่าได้
- เพิ่มคำสั่ง LOGTEST ทางสาย USB ให้ร้านเช็คว่ากุญแจในบอร์ดเซ็นได้ และใช้เวลาเท่าไร

- อ่านค่าจาก ELM327 หกค่า: รอบเครื่อง, ความเร็ว, อุณหภูมิน้ำ, ลิ้นปีกผีเสื้อ, MAP, แรงดันไฟ ECU

- ตัวเลขบนจอค่อย ๆ วิ่งเข้าหาค่าจริง ไม่กระโดด แถบรอบเครื่องใช้ตัวเลขที่กำลังวิ่งอยู่
- ตัวเลขวาดลงบัฟเฟอร์แล้วส่งขึ้นจอครั้งเดียว
- บันทึกค่าลง MicroSD

[หน้าจอ]
- หกหน้า: ไลฟ์, การเชื่อมต่อ, สแกนอุปกรณ์, ลิมิตแจ้งเตือน, ธีม, แฟลช
- ปัดเปลี่ยนหน้า จุดนำทางอยู่กลางจอ ชื่อและตัวเลขบนการ์ดเป็นสีขาว หน่วยอยู่ใต้ตัวเลข
- หัวหน้าไลฟ์คือ R0CKY GAUGES
- คาลิเบรตสัมผัสเก็บในตัวบอร์ด
- ลิมิตเก็บในตัวบอร์ด ค่าเริ่มต้นรอบเครื่อง 7500 ใส่ 0 คือปิด แบตเตอรี่เตือนเมื่อแรงดันต่ำกว่าที่ตั้ง
- เกินลิมิตแล้วเป็นชิฟต์ไลต์ทั้งจอ สีแดงสลับดำ ตัวเลขใหญ่ตรงกลาง ไม่เหลือแถบเมนู
- แถบด้านบนเปลี่ยนจากเขียวไปแดงเมื่อรอบเครื่องเข้าใกล้ลิมิต เริ่มที่ 80%

[การเชื่อมต่อ]
- ต่อได้สองทาง: Wi-Fi TCP และ BLE ตั้งค่าจากไฟล์ obd_config.ini บน MicroSD
- สแกนหาอุปกรณ์แล้วแตะเพื่อเชื่อม ดองเกิลชื่อเดียวกัน เช่น V-LINK แยกด้วย MAC
- เปลี่ยน SSID แล้วตัดการเชื่อมเก่า และล้างที่อยู่ ELM ที่จำไว้ ต่อเข้าเกตเวย์ของ Wi-Fi ก่อนที่อยู่เก่าบนการ์ด
- Wi-Fi ที่มีรหัสกรอกจากหน้า WIFI PASS รหัสเก็บในบอร์ด ไม่เขียนลงการ์ด
- ต่อ Wi-Fi บ้านได้แม้ไม่มี ELM สถานะขึ้น WiFi online, no ELM และไม่ตัดเน็ตทิ้ง
- บูตครั้งถัดไปต่อ Wi-Fi ที่จำไว้ให้อัตโนมัติ กด DISCONNECT แล้วบูตครั้งถัดไปจะไม่ต่อเอง
- BLE ใช้ได้เมื่อมีที่อยู่กับ UUID ในไฟล์ตั้งค่า
- รถที่ลอง: Civic FD, FB, FC ใช้ CAN ชุดเดียวกัน ล็อกโปรโตคอล 6 ก่อน แล้ว 7 แล้วให้ ELM ค้นเอง
- ลอง ATZ ได้สามครั้ง ไม่รีเซ็ต ELM ซ้ำระหว่างอ่านค่า
