R0CKY GAUGES - esp32-3.5 changelog (จอ 3.5")
============================================

1.2.1 (2026-11-11)
------------------

[การเชื่อมต่อ]
- SCAN แสดงเฉพาะอุปกรณ์ที่มีชื่อ ไม่มี (unnamed BLE) และ WiFi ที่ซ่อนชื่อแล้ว (ตัว OBD ที่ไม่มีชื่อแต่เป็นบริการ FFF0 ยังขึ้นเป็น (OBD FFF0))
- หน้ากรอกรหัส WiFi: ชื่อ WiFi ย้ายขึ้นไปอยู่แถวบนข้างคำว่า WiFi ช่องกรอกรหัสไม่บังชื่อแล้ว สีเปลี่ยนเป็นชุดเดียวกับหน้าอื่น (การ์ดเข้ม ขอบบาง ปุ่ม OK สีส้ม) ไม่ใช้สีแดงแล้ว ข้อความเตือนเป็นสีเหลืองอำพัน

[เครื่องมือ]
- คำสั่ง serial TAP=x,y จำลองการแตะจอ ไว้ทดสอบบนโต๊ะ

1.2.0 (2026-11-10)
------------------

[หน้าจอ]
- หน้าตาใหม่ทั้งหมดแบบเรียบ ชุดเดียวกับจอ 2.8": พื้นดำ การ์ดสีเข้มขอบบาง สีหลักส้มสีเดียว ตัวหนังสือ Rajdhani ตัวหนา
- หน้า DASH: การ์ด 6 ช่อง (SPEED, RPM, BOOST, THROTTLE, COOLANT, BATT) มีแถบสีด้านซ้าย ชื่อสีตามช่อง หน่วยมุมขวาบน ตัวเลขขาวตัวใหญ่ วาดใหม่เฉพาะช่องที่ค่าเปลี่ยน
- หน้า BOOST & PEAK: บูสต์ตัวใหญ่ + แถบ -1 ถึง 1.5 bar (ขีดแดงคือค่าสูงสุด), เวลา 0-100, ค่าสูงสุดของรอบ ความเร็ว น้ำ และปุ่ม RESET
- หน้า DEVICES, ALERT LIMITS, LOG, TROUBLE CODES ออกแบบใหม่ให้เข้าชุด หน้า TROUBLE CODES บอกระบบที่โค้ดนั้นเกี่ยว (เช่น Ignition or misfire)
- หน้า LOG GRAPH เป็นเส้นกราฟ: แตะชื่อค่าที่หัวหน้าเพื่อเปลี่ยนค่าที่ดู แตะ < FILES เพื่อกลับไปรายการไฟล์
- เอาหน้า COLOR ออก (สีหลักเป็นส้มตายตัว) หน้า FLASH เปลี่ยนชื่อเป็น SYSTEM
- หน้า SYSTEM: ขึ้น UPDATE ... READY เฉพาะเมื่อไฟล์ในการ์ดใหม่กว่ารุ่นที่ใช้อยู่ ถ้าเก่ากว่าจะขึ้น OLDER ... ON THE CARD
- หน้าเตือนเต็มจอแบบใหม่: พื้นแดง ตัวเลขใหญ่ และบอกค่าที่ตั้งไว้

1.1.5 (2026-11-10)
------------------

[หน้าจอ]
- แก้ปัดเปลี่ยนหน้าแล้วหน่วง/ค้างตอนต่อ OBD อยู่: การบันทึก log ลง SD card ย้ายไปทำเบื้องหลัง ไม่หยุดหน้าจอแล้ว
- ตอนเพิ่งต่อ OBD ติด จอไม่ค้างไปครู่หนึ่งเหมือนก่อน (ตอนเปิดไฟล์ log ใหม่)

1.1.4 (2026-11-10)
------------------

[การเชื่อมต่อ]
- แก้จอค้าง/รีบูตเองตอนต่อ OBD แบบ Bluetooth ขณะตัวแปลงส่งข้อมูลมาเยอะ
- ใช้ WiFi OBD แล้วจะปิด Bluetooth ให้ ไม่แย่งวิทยุกัน ค่าบนจอไม่กระตุกหรือหลุดบ่อย
- ต่อ OBD เร็วขึ้น: ข้ามที่อยู่ที่ไม่ตอบเลย และลดเวลารอเมื่อตัวแปลงหรือรถไม่ตอบ ไม่ค้างที่หน้าสถานะนาน

1.1.3 (2026-11-10)
------------------

[การเชื่อมต่อ]
- ถ้าหาตัวแปลง WiFi OBD ที่ที่อยู่ปกติไม่เจอ จะไล่หาในวงเดียวกัน (.1 ถึง .30 พอร์ต 35000) ให้อัตโนมัติ
- ถ้ายังไม่เจอ จอจะบอก IP ของจอและ gateway (No ELM me=... gw=...) เพื่อใช้ตรวจปัญหา
- ต่อ V-LINK ได้ดีขึ้น: รอตัวแปลงพร้อมหลังต่อ WiFi และรอตอบนานขึ้น ลองซ้ำ 3 รอบ

1.1.2 (2026-11-09)
------------------

[การเชื่อมต่อ]
- ต่อ WiFi OBD อย่าง V-LINK / Vgate ได้ แม้ตัวแปลงไม่ได้ตั้ง gateway เป็นตัวเอง (ลองที่อยู่ .10 และ 192.168.0.10 ให้อัตโนมัติ)
- ถ้าตัวแปลงตอบแล้วแต่รถยังไม่ติดเครื่อง จะขึ้น "ELM OK - ..." แทน "no ELM" และลองต่อใหม่เองทุก 15 วินาที
- ถ้าพอร์ตเปิดแต่ตัวแปลงไม่ตอบ จะบอกที่อยู่และพอร์ตบนจอ

1.1.1 (2026-11-07)
------------------

[หน้าจอ]
- โหมดทดสอบ DEMO (สั่งทาง serial) แสดงค่าตัวอย่างบนหน้า BOOST & PEAK ด้วย ใช้ถ่ายภาพหน้าจอ ไม่กระทบการใช้งานปกติ

1.1.0 (2026-11-06)
------------------

[หน้าจอ]
- เพิ่มหน้า BOOST & PEAK (ปัดต่อจากหน้า DASH): บูสต์เป็น bar (ค่า MAP ลบ 101 kPa ติดลบคือสุญญากาศ) พร้อมค่าบูสต์สูงสุด
- เก็บค่าสูงสุดของรอบ ความเร็ว และอุณหภูมิน้ำ กดปุ่ม RESET เพื่อล้างค่า
- จับเวลา 0-100 กม./ชม. หยุดรถให้ขึ้น READY แล้วออกตัว จอจับเวลาให้เอง เก็บเวลาล่าสุดและดีที่สุด (ความละเอียดตามความถี่ที่อ่านความเร็วจาก OBD)

1.0.0 (2026-11-06)
------------------

[หน้าจอ]
- หน้า DASH แบบ RACE: แถบรอบเครื่อง ความเร็ว THROTTLE WATER BATT MAP
- หน้า DEVICES สแกน WiFi/BLE แตะเลือกต่อ OBD รายการเลื่อนตามนิ้วแบบสมูท สแกนทำงานเบื้องหลังหน้าจอไม่ค้าง
- แตะ WiFi ที่มีรหัสผ่านจะมีแป้นพิมพ์ให้กรอกรหัสผ่าน (แตะป้าย LOCK เพื่อกรอกใหม่) ไม่ต้องส่ง PASS= ทางสาย USB
- หน้า ALERT LIMITS ตั้งค่าเตือนรอบ/ความเร็ว/น้ำ/คันเร่ง/MAP/แบต และปรับความเร็วให้ตรง (SPEED CAL)
- หน้า COLOR เลือกสีธีม
- หน้า LOG ดูไฟล์ล็อกจาก SD และกราฟของค่าแต่ละตัว (ซูม 60/30/10 วินาที เลื่อนซ้ายขวา)
- หน้า DTC อ่านโค้ดเสีย (STORED / PENDING) และล้างโค้ด
- หน้า FLASH อัพเดทเฟิร์มแวร์ผ่านเว็บหรือไฟล์ dash35.bin ในการ์ด SD
- ปัดซ้าย-ขวาเปลี่ยนหน้า ส่งภาพทั้งจอใหม่ทุก 1 วินาที กันจอค้างภาพเดิม

[ล็อก]
- บันทึกล็อกลง SD เซ็นและเข้ารหัสแบบเดียวกับจอ 2.8" เปิดใน LogViewer ได้
- บันทึกไทมิ่ง AFR และ injector duty (ตั้งด้วย INJ=...) เหมือนจอ 2.8"
- ใส่ key ร้านจาก ShopTool ได้ (แก้บัฟเฟอร์ USB รับคำสั่ง LOGCERT= ไม่ครบ)

[ระบบ]
- แก้จอและทัชช้า/ค้างเมื่อเสียบสาย USB แต่ไม่ได้เปิด Serial Monitor
- แก้บอร์ดรีบูตตอนเข้าหน้า FLASH ขณะต่อ WiFi
- เฟิร์มแวร์ขึ้นเว็บเป็น dash35.bin / health35.txt / changelog35.txt แยกจากจอ 2.8"
