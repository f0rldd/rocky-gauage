สถานการณ์ขับ

หน้าค่า: เลือกค่าที่อยากดูเอง

พื้นดำ ตัวเลขขาว ชื่อค่าและหน่วยสีเทา ไม่มีชื่อหน้าหรือโลโก้ กดค้างที่ตัวเลขประมาณครึ่งวินาที จะขึ้นรายการ 25 ค่าให้เลือก (รอบ ความเร็ว MAP บูสต์ ไทมิ่ง AFR น้ำมันเครื่อง fuel trim อากาศเข้า ฯลฯ) แต่ละหน้าจำค่าของตัวเองแยกกัน ดูความหมายของทุกค่าได้ที่ตารางค่าที่อ่านได้

ในหน้าจำลองนี้ RAIL PRS, CAT TEMP, TRAN TEMP และ INJ DUTY ขึ้น -- เหมือนรถที่ไม่ส่งค่านั้น ลองเลือกดู

หกหน้าที่ปัดผ่าน

  • หน้าค่า 1 9 ค่า (3 x 3) บนจอ 3.5" (จอ 2.8" แสดง 4 ค่า) RPM เป็นสีแดงเมื่อใกล้รอบเตือน เกินลิมิตแล้วมีแถบเตือนสีเหลืองขึ้นด้านล่าง (ลอง "ชนลิมิต")
  • หน้าค่า 2 4 ค่า (2 x 2) ตัวเลขใหญ่ขึ้น หน้าค่า 3 2 ค่าซ้ายขวา ตัวเลขใหญ่สุด
  • DEVICE รายชื่อ ELM327 Bluetooth กด SCAN แล้วกด Connect ตัวที่ต่ออยู่มีแถบสีและคำว่า Connected กด Disconnect ทางขวาเพื่อตัด
  • CONNECTION Wi-Fi สำหรับดาวน์โหลดเฟิร์มแวร์ เลือกเครือข่าย ใส่รหัสผ่านด้วยแป้นพิมพ์ แล้วกด Connect
  • SYSTEM รายการตั้งค่า (สีเน้น พื้นหลัง การ์ด) แล้วเปิดหน้าย่อยได้: FIRMWARE, ALERT LIMIT, SPEED CAL, DRIVE LOGS, TROUBLE CODES ปัดไปทางไหนก็กลับมา SYSTEM

หน้าย่อยจาก SYSTEM

  • FIRMWARE เทียบรุ่นที่ติดตั้ง รุ่นในการ์ด SD และรุ่นบนเว็บ DOWNLOAD ลงการ์ด แล้ว INSTALL ต้องยืนยันก่อนเขียน ต่อ Wi-Fi ที่หน้า CONNECTION ก่อนจึงโหลดได้ (ลองในหน้านี้ได้ ไม่ได้เขียนเฟิร์มแวร์จริง)
  • ALERT LIMIT รายการเตือนรอบ ความเร็ว น้ำ คันเร่ง MAP แบตต่ำ เปิด/ปิดด้วยสวิตช์ แตะแถวเพื่อแก้ค่าด้วยปุ่ม - + แล้ว SAVE
  • DRIVE LOGS ไฟล์ล็อกในการ์ด SD แตะไฟล์เพื่อดูกราฟ แตะชื่อค่าด้านบนเพื่อเปลี่ยนค่า ปุ่มกลางซูม < > เลื่อนช่วงเวลา ไฟล์ที่ขึ้น Recording คือไฟล์ที่กำลังบันทึกจากหน้าจำลองนี้
  • TROUBLE CODES อ่านโค้ดเสียที่เก็บไว้และที่รอยืนยัน บอกว่าโค้ดเกี่ยวกับระบบไหน ล้างไฟเตือนต้องกดยืนยันสองครั้ง

อย่างอื่นที่บอร์ดทำได้

  • บันทึกล็อกลงการ์ด SD ทุก 0.5 วินาที เก็บทุกค่าที่รถรองรับ (สูงสุด 24 ค่า) ไฟล์เซ็นลายเซ็นดิจิทัลและเข้ารหัส เปิดดูด้วย R0CKY LogViewer
  • จำอุปกรณ์ที่ต่อไว้ เปิดรถแล้วต่อเองอัตโนมัติ รหัส WiFi เก็บในตัวบอร์ด ไม่เขียนลงการ์ด
  • อัพเดทเฟิร์มแวร์จากหน้า SYSTEM ผ่าน WiFi หรือใส่ไฟล์ในการ์ด SD
