0.6.1 (2026-11-26)
------------------

[หน้า BUTTONS]
- แก้ปุ่มส่งค่าไม่ตรงเลขปุ่ม (ปุ่ม 3 ส่ง 4, ปุ่ม 4 ส่ง 8 ...): จอที่ยังจำการตั้งปุ่มแบบ Custom จากรุ่นเก่า (ทุกปุ่มอยู่ในไบต์ 0 ปุ่มละบิต) กลับเป็นแบบ Standard เองตอนเปิดเครื่อง: ID 0x5F0 ไบต์ 0 = ปุ่ม 1 ... ไบต์ 7 = ปุ่ม 8 ค่าในไบต์ = เลขปุ่มตอน ON (ปุ่ม 3 = 0x03 ในไบต์ 2) และ 0 ตอน OFF ใน MTune ตั้ง Byte offset = เลขปุ่ม - 1, Bit mask = เลขปุ่ม

0.5.0 (2026-11-25)

[ธีม]
- เพิ่มธีม Race: แถบรอบเครื่องเฉียง 0-9 (เขียว / เหลืองที่ 6000 / แดงที่ 8000) ไล่ตามรอบจริงต่อเนื่อง ความเร็วตัวใหญ่กลางจอ กล่องเกียร์ด้านขวา และช่องค่า 5 ช่องด้านล่าง พื้นดำเส้นเขียวมินต์
- ช่องล่างของธีม Race เริ่มต้นเป็น WATER, OIL, FUEL P, BATT, FUEL แตะค้างที่ช่องเพื่อเลือกค่าอื่น (จำไว้แยกจากธีมอื่น) แรงดันน้ำมันเครื่อง / เชื้อเพลิง / น้ำ แสดงเป็น bar ส่วน FUEL แสดงเป็นลิตรตามที่กล่อง MaxxECU ส่ง
- สลับธีมวน Haltech > AEM > Race (แตะกลางจอ หรือแถว THEME ใน SETTINGS) ปัดขึ้น = ธีมถัดไป ปัดลง = ธีมก่อนหน้า
- โหมด DEMO มีค่าแรงดันเชื้อเพลิงและน้ำมันในถัง

0.4.1 (2026-11-24)
------------------

[ทัชและการเปลี่ยนหน้า]
- แก้กดปุ่มแล้วหน้าเลื่อนไปหน้าอื่นเอง: เมื่อปุ่มถูกกดแล้ว นิ้วนั้นเป็นของปุ่มจนกว่าจะยก ลากไปไกลแค่ไหนก็ไม่เปลี่ยนหน้าและปุ่มไม่ถูกยกเลิก (เดิมระบบเข้าใจผิดว่ายกนิ้วแล้วทั้งที่ยังกดอยู่ จึงนับเป็นการแตะ/ปัดครั้งใหม่ซ้ำ ๆ)
- ปัดหนึ่งครั้งเปลี่ยนหน้าเดียวเสมอ: ต้องยกนิ้วก่อนจึงปัดครั้งต่อไปได้ และการแตะระหว่างที่จอกำลังเปลี่ยนหน้าไม่ไปโดนปุ่มของหน้าใหม่
- การปัดต้องเลื่อนอย่างน้อย 120 px ภายใน 0.6 วินาทีหลังแตะ วางสองนิ้วพร้อมกันหรือจุดสัมผัสกระโดดไม่นับเป็นการปัด
- นิ้วหลุดจากจอชั่วขณะ (จอสั่น แตะเบา ไม่เกิน 0.04 วินาที) ไม่นับเป็นการยกนิ้ว ปุ่มไม่ติด/ดับซ้ำ
- กดปุ่มหน้า BUTTONS แล้วนิ้วขยับเล็กน้อยก็ติด (นิ่ง 0.09 วินาที หรือขยับไม่เกิน 40 px ครบ 0.22 วินาที)
- แตะค้าง 3 วินาทีเพื่อปรับทัช ใช้ได้เฉพาะหน้าแดช (เดิมหน้าอื่นก็เข้าโหมดปรับทัชเอง) หน้าอื่นใช้แถว TOUCH ใน SETTINGS
- หน้าปรับทัช: แก้จอกลับหัว และเพิ่มจุดจาก 4 เป็น 9 จุดทั่วจอให้แม่นขึ้น กดค้างจนจุดเป็นสีเขียวแล้วยกนิ้ว ถ้านิ้วขยับหรือยกเร็วไปจะให้กดจุดเดิมซ้ำ ไม่แตะ 30 วินาทีออกเองและใช้ค่าเดิม
- หน้าพิมพ์รหัส Wi-Fi ปัดแล้วไม่ออก (รหัสที่พิมพ์ไม่หาย) ออกด้วยปุ่ม CANCEL

[ความเร็ว]
- หน้าแดช Haltech ลื่นขึ้นมาก: วาดต่อภาพจาก 69 เหลือ 14 ms (โหมด DEMO) เมื่อค่าเปลี่ยนพร้อมกันหลายช่อง ตัวเลขผลัดกันวาด เข็มจึงไม่สะดุด
- เปลี่ยนหน้าเร็วขึ้น: BUTTONS จาก 750 เหลือ 53 ms, SETTINGS จาก 247 เหลือ 48 ms, หน้าเลือกค่าจาก 281 เหลือ 62 ms, กลับหน้าแดชจาก 108 เหลือ 41 ms
- ไฟปุ่มหน้า BUTTONS เปลี่ยนสถานะเร็วขึ้น จาก 111 เหลือ 7 ms ต่อปุ่ม
- เข้าหน้า FIRMWARE ครั้งแรกจอขึ้นหน้าทันทีพร้อมข้อความ Starting Wi-Fi...
- กลับหน้าแดชแล้วค่าขึ้นพร้อมหน้าทันที ไม่เห็นช่องว่างก่อน
- แก้ค่าหรือ NO CAN กะพริบเป็น -- แวบหนึ่งทั้งที่ CAN ปกติ

0.4.0 (2026-11-23)

[อัพเดทเฟิร์มแวร์]
- เพิ่มหน้า FIRMWARE (เปิดจากหน้า SETTINGS แถว FIRMWARE, ปัดขวาหรือกด BACK เพื่อกลับ): ดูรุ่นปัจจุบันกับรุ่นบนเว็บ เลือกเครือข่าย Wi-Fi จากรายการ พิมพ์รหัสผ่านด้วยคีย์บอร์ดบนจอ (จำไว้ ครั้งต่อไปต่อเอง) แล้วกด UPDATE ดาวน์โหลดและเขียนเฟิร์มแวร์ลงเครื่อง เสร็จแล้วรีสตาร์ทเอง ไม่ต้องใช้ SD การ์ด
- เปลี่ยนหน้าเร็วขึ้น: ปัดเกิน 100 px จอเปลี่ยนหน้าทันทีโดยไม่ต้องรอยกนิ้ว (เดิมต้องปัด 140 px แล้วรออีกประมาณ 0.3 วินาทีหลังยกนิ้ว)
- เพิ่มหน้า SETTINGS แบบเดียวกับ SYSTEM ของจอ 2.8" / 3.5" (ปัดซ้ายจากหน้า BUTTONS ปัดขวาหรือกด BACK เพื่อกลับ): THEME สลับ Haltech / AEM, FIRMWARE เปิดหน้าอัพเดท, TOUCH ปรับทัชใหม่, DEMO เปิด/ปิดโหมดทดลอง (ค่าจำลองวิ่งผ่านเกียร์ 1-5 ให้ดูหน้าแดชโดยไม่ต่อรถ ไม่ได้บันทึก ปิดเองเมื่อรีสตาร์ท), DEVICE รีสตาร์ท (แตะสองครั้ง)
- จัดเลย์เอาต์ธีม AEM ใหม่: ช่องซ้าย ขวา และแถวล่างกว้างเท่ากันทุกช่อง (4 คอลัมน์ ระยะห่างเท่ากัน) การ์ดกลางกับกล่องเกียร์จัดกึ่งกลาง และข้อความในช่องใช้พื้นที่เต็มช่อง (เดิมหลบวงแหวนของธีม Haltech ทำให้ชื่อค่าเยื้องและตัดขอบ)
- จัดธีม Haltech ใหม่ให้เหมือนจอ Haltech จริง: ช่องมุมขวาล่างในวงเป็น GEAR (ช่องแคบ) กับ KM/H ด้านบน และ RPM ด้านล่าง ค่าตัวใหญ่ ชื่อค่าอยู่ใต้ค่า ตายตัว (แตะค้างเปลี่ยนค่าไม่ได้ในสามช่องนี้) เอาเลขเกียร์ / รอบเครื่องที่เคยอยู่กลางวงออก ปล่อยกลางวงว่างเหลือแต่เข็ม
- เข็มรอบเครื่องธีม Haltech กวาดลื่นขึ้น: เข็มวิ่งตามค่ารอบแบบหน่วงสั้น ๆ (ประมาณ 45 ms) ต่อเนื่องระหว่างค่าที่เข้ามาทาง CAN วาดสูงสุดประมาณ 60 ภาพต่อวินาที (เดิม 30) และวาดเฉพาะบริเวณรอบเข็มจริง (เล็กลงประมาณครึ่งหนึ่ง) บรรทัดสถานะทาง Serial ทุก 2 วินาทีมีเวลาวาดต่อภาพ (draw n= avg= max=) ไว้ตรวจ
- ธีม Haltech ช่องซ้ายขวา: ตัวเลขสีเหลืองอำพัน ชื่อค่าอยู่ใต้ตัวเลข ชิดซ้ายของช่อง (เหมือนจอ Haltech จริง) ธีม AEM ไม่เปลี่ยน
- ธีม Haltech ช่องซ้ายขวามีแท่งไฟ 6 ขีดที่ขอบนอกของช่อง ติดจากล่างขึ้นบนตามค่า (เช่น น้ำ 40-120 °C, แบต 10-15 V, AFR 10-18, บูสต์ -1 ถึง 2 bar, TPS 0-100 %) ค่าที่ไม่มีช่วง เช่น เกียร์ ไม่มีแท่ง
- ตัวเลขในช่องของธีม Haltech และ AEM ใหญ่ขึ้น (เพิ่มฟอนต์ตัวเลขขนาด 76 / 88 / 100 px ระบบเลือกตัวที่ใหญ่ที่สุดที่ยังพอดีช่อง) ช่องในวงของ Haltech (เกียร์ / ความเร็ว / รอบ) ก็ใหญ่ขึ้นด้วย
- แก้ตัวเลขในช่องเปลี่ยนขนาดเองเมื่อจำนวนหลักเปลี่ยน (เช่น RPM 999 → 1000 ตัวหนึ่งใหญ่ตัวหนึ่งเล็ก) ตอนนี้แต่ละช่องใช้ขนาดตัวเลขคงที่ตามค่าที่กว้างที่สุดที่ช่องนั้นอาจแสดง (คิดจากช่วงค่าและทศนิยมของค่านั้น) ทั้งธีม Haltech และ AEM
- ธีม AEM: คำว่า RPM ย้ายมาอยู่ใต้ตัวเลขรอบเครื่อง (เดิมอยู่ด้านบน)
- ธีม Haltech: คำว่า RPM / GEAR / KM/H ในช่องมุมขวาล่างวางชิดใต้ตัวเลขและอยู่ในกรอบวง (เดิมช่อง RPM ล่างสุดอยู่ใกล้ขอบจนหลุดออกนอกกรอบ)
- ธีม Haltech: ตัวเลขและชื่อค่าของช่อง GEAR กับ RPM ชิดซ้ายที่แนวเดียวกัน (ช่อง KM/H ยังอยู่กึ่งกลางช่อง)
- ออกแบบหน้า BUTTONS ใหม่เป็นแผงปุ่มกดแบบคีย์แพด CAN: ช่องยางสี่เหลี่ยม ปุ่มกลมจมลงไป มีวงแหวนไฟ ขอบนูนไล่เงา และหน้าปุ่มโค้งมีประกายแสง ตอน ON หน้าปุ่มเป็นสีเหลืองอำพันและวงแหวนเรืองแสง ส่งแล้วแต่กล่อง ECU ยังไม่ยืนยันจะมีวงแหวนเหลืองและขึ้น WAIT
- หน้า BUTTONS กดแล้วติดเร็วขึ้น: ปุ่มทำงานเมื่อวางนิ้วนิ่งประมาณ 80 ms ไม่ต้องรอยกนิ้ว (เดิมรอ 0.2-0.3 วินาทีหลังยกนิ้ว) วาดใหม่เฉพาะปุ่มที่เปลี่ยน (เดิมวาดทั้งหน้า 8 ปุ่ม) และตรวจสถานะจากกล่องทุก 40 ms
- หน้า BUTTONS กดค้างได้: แตะสั้นปุ่มจะค้าง ON (แตะอีกทีปิด) กดค้างตั้งแต่ 0.4 วินาทีขึ้นไปปุ่มจะ ON อยู่ตราบที่นิ้วยังกดอยู่ ยกนิ้วแล้วปิดทันที (ปุ่มโหมด PULSE ไม่เปลี่ยน) และการกดค้างบนหน้านี้ไม่เข้าโหมดปรับทัชแล้ว
- หน้า BUTTONS ปัดเปลี่ยนหน้าแล้วไม่โดนปุ่ม: นิ้วที่ขยับเกิน 10 px ก่อนครบ 80 ms ถือเป็นการปัด ไม่กดปุ่ม ถ้าปัดช้าจนกดปุ่มไปแล้ว ระบบยกเลิกการกดนั้นให้ก่อนเปลี่ยนหน้า
- ไฟล์บนเว็บคือ maxx7.bin / healthmaxx7.txt / changelogmaxx7.txt ลงด้วย python upload_server.py --board 7-maxx
- รุ่นนี้ต้องแฟลชสาย USB ครั้งหนึ่ง หลังจากนั้นอัพเดททาง Wi-Fi ได้ (ตารางพาร์ทิชันเดิมมีช่อง OTA สองช่องอยู่แล้ว)

0.3.1 (2026-11-23)
------------------

[หน้า BUTTONS]
- ปุ่มส่งเข้ากล่องแบบ Standard เปลี่ยนใหม่: ID 0x5F0 ปุ่มละไบต์ (ไบต์ 0 = ปุ่ม 1 ... ไบต์ 7 = ปุ่ม 8) ค่าในไบต์ = เลขปุ่ม (1-8) ตอนกด และ 0 ตอนปล่อย ทำให้ Current value ใน MTune ตรงกับเลขปุ่ม (เดิมเป็นบิตมาสก์ จึงได้ 1 2 4 8 16 32 64 128) ไม่มีตัวนับในไบต์ 1 แล้ว
- เอาหน้า SETUP ออก หน้า BUTTONS เหลือแค่ปุ่ม 8 ปุ่มเต็มจอ ไม่มีชื่อหน้า สถานะ ปุ่ม BACK / SETUP / สวิตช์ล็อก (ปัดขวากลับแดช) ปุ่มทำงานทันทีที่เข้าหน้านี้ และปล่อยทั้งหมดเมื่อออก
- ต้องตั้ง MTune ใหม่: CAN input ปุ่มละ 1 ช่อง ไบต์ตามเลขปุ่ม unsigned 8 bit (โหมด Custom ไม่เปลี่ยน)

------------------

[หน้าจอ]
- สลับธีม Haltech / AEM ได้ด้วยการปัดจอขึ้นหรือลงบนหน้าแดช (เพิ่มจากการแตะตรงกลาง) และพื้นที่แตะตรงกลางของ AEM กว้างขึ้นครอบทั้งการ์ดรอบและเกียร์

[หน้า BUTTONS]
- เข้าหน้า BUTTONS แล้วจะไม่ส่งอะไรไปที่กล่อง ECU: ทุกครั้งที่เข้าหน้านี้ปุ่มล็อกไว้ก่อน (BUTTONS OFF ปุ่มทุกปุ่มปล่อย) ต้องแตะสวิตช์ BUTTONS ที่มุมขวาบนเพื่อปลดล็อกเอง และเมื่อออกจากหน้า (ปัดกลับแดช หรือเข้า SETUP) จะล็อกและปล่อยปุ่มทั้งหมดอีกครั้ง
- เพิ่มหน้า SETUP (ปุ่ม SETUP ในหน้า BUTTONS) ตั้งค่าปุ่ม: โหมด STANDARD / CUSTOM, ปุ่มที่กำลังตั้ง, ประเภท TOGGLE / PULSE, ID ที่ส่ง, ไบต์, บิต, ID ที่รับสถานะจาก ECU, ไบต์ บิต และดูสถานะตอนนี้ (ชุดตัวเลือกเดียวกับจอ 2.8" / 3.5") แตะแถวเพื่อเปลี่ยน แตะแถว ID เพื่อเปิดตัวแก้เลขฐาน 16 ปัดไปทางขวาเพื่อกลับ

0.2.0 (2026-11-23)
------------------

[หน้าจอ]
- กดค้างที่ช่องค่า (0.6 วินาที) เพื่อเปลี่ยนค่าที่ช่องนั้นแสดง เลือกได้จาก 47 ค่า (หน้าละ 24 ค่า มี PREV / NEXT) จำค่าไว้หลังปิดเครื่อง ทำได้ทั้งธีม Haltech และ AEM
- เพิ่มหน้า BUTTONS: ปุ่ม 8 ปุ่มส่งสัญญาณไปที่ MaxxECU (เหมือนจอรุ่น 2.8" / 3.5") แสดงสถานะปุ่มจริงจาก ECU ปัดจอไปทางซ้ายจากหน้าแดช เปิดใช้ปุ่มด้วยสวิตช์ BUTTONS ON/OFF (ค่าเริ่มต้นปิด) ตั้งชื่อปุ่มด้วยคำสั่งซีเรียล BTNNAME=1,LAUNCH
- การสลับธีม Haltech / AEM เปลี่ยนเป็นแตะตรงกลางหน้าแดช (บริเวณเกียร์ / รอบ) เพราะแตะที่อื่นไม่สลับแล้ว
- ปัดจอไปทางขวาเพื่อกลับหน้าแดช

0.0.1 (2026-11-22)
------------------

[โครงโปรเจกต์]
- เริ่มเฟิร์มแวร์จอ 7" (Waveshare ESP32-P4-WIFI6-Touch-LCD-7B) สำหรับ MaxxECU: จอ 1024x600, ทัช GT911, อ่านค่า CAN 500 kbit/s จาก MaxxECU ด้วยตัวถอดรหัสเดียวกับจอรุ่นอื่น (shared/maxxecu/maxx_can.h)

[หน้าจอ]
- หน้าตา 2 แบบ: Haltech (วงรอบมีเข็ม ช่องค่า 11 ช่อง) และ AEM (แถบไฟเลื่อนเกียร์ ไฟ 8 ดวง รอบตัวใหญ่ ช่องค่า 8 ช่อง) แตะจอที่ไหนก็ได้เพื่อสลับ จำค่าไว้หลังปิดเครื่อง
- แสดง NO CAN สีแดงด้านบนเมื่อ ECU ไม่ส่งข้อมูล

[หน้าจอ]
- กลับภาพ 180 องศา (บอร์ดที่ทดสอบแสดงภาพกลับด้าน) ตั้งได้ที่ DISPLAY_FLIP_X / DISPLAY_FLIP_Y ใน include/board_pins.h ถ้าเปลี่ยนต้องคาลิเบรตทัชใหม่

[ทัช]
- คาลิเบรตทัชสี่จุด (กดค้างจุดแดงทีละจุด) เริ่มเองตอนเปิดเครื่องครั้งแรก หรือกดนิ้วค้างบนจอ 3 วินาที หรือกดนิ้วค้างไว้ตอนเปิดเครื่อง หรือส่งคำสั่ง CAL ทางสาย USB (CALRESET ล้างค่า) ค่าถูกบันทึกไว้หลังปิดเครื่อง ถ้าความคลาดเคลื่อนเกิน 28 px ให้ทำใหม่
- แก้บั๊กอ่านพิกัดทัชผิดไบต์ (ทำให้คาลิเบรตขึ้น TOO INACCURATE ทุกครั้ง)
- ยังไม่มีหน้าตา APEX บนจอ 7" ยังไม่มีเลือกค่าที่แสดงในแต่ละช่อง ยังไม่มีการอัพเดตเฟิร์มแวร์ผ่าน Wi-Fi
