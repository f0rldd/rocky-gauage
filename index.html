Features

ทุกอย่างที่เกจดีๆ ควรมี ในจอเดียว

ออกแบบมาให้อ่านง่ายในรถ ตัวเลขใหญ่ ปุ่มกดง่าย และทำงานได้ทันทีหลังต่อ ELM327

ค่าสดจากรถ 6 ตัว

รอบเครื่อง ความเร็ว อุณหภูมิน้ำ ตำแหน่งคันเร่ง MAP และแรงดันแบตเตอรี่ อัพเดทต่อเนื่อง ปรับความเร็วให้ตรงกับมาตรวัดรถได้

เตือนเมื่อเกินลิมิต

ตั้งค่าเตือนรอบ ความเร็ว น้ำ คันเร่ง MAP และแบตต่ำ ทั้งหน้าจอเปลี่ยนเป็นสีแดงเต็มจอทันทีที่เกินค่าที่ตั้ง

อ่านและล้างโค้ดเสีย (DTC)

อ่านโค้ดที่เก็บไว้และโค้ดที่รอยืนยัน แล้วล้างไฟเตือนได้จากหน้าจอ มีขั้นตอนยืนยันก่อนล้างทุกครั้ง

บูสต์ ค่าสูงสุด และจับเวลา 0-100

หน้า BOOST & PEAK โชว์บูสต์เป็น bar พร้อมค่าสูงสุด เก็บรอบ ความเร็ว และน้ำสูงสุดของรอบนั้น จับเวลา 0-100 กม./ชม. ให้เองเมื่อออกตัว กด RESET เพื่อล้างค่า

บันทึกล็อกลงการ์ด SD

บันทึกทุกครึ่งวินาทีขณะขับ เก็บไทมิ่ง AFR และ injector duty ด้วย ไฟล์ล็อกเซ็นลายเซ็นดิจิทัลและเข้ารหัส ตรวจได้ว่าไม่ถูกแก้

WiFi และ Bluetooth LE

สแกนแล้วแตะเลือกอะแดปเตอร์ได้ในหน้าจอ รหัสผ่าน WiFi พิมพ์ผ่านแป้นพิมพ์บนจอ จำการเชื่อมต่อและต่อใหม่อัตโนมัติเมื่อเปิดรถ

อัพเดทเฟิร์มแวร์เอง

กดโหลดจากเว็บแล้วแฟลชจากหน้าจอได้เลย หรือใส่ไฟล์ในการ์ด SD เห็นเลขรุ่นปัจจุบัน รุ่นในการ์ด และรุ่นบนเว็บเทียบกัน

FAQ

คำถามที่พบบ่อย

ใช้กับรถรุ่นไหนได้บ้าง

รถที่มีช่องวินิจฉัย OBD2 และใช้งานกับ ELM327 ได้ ค่าที่อ่านเป็นค่ามาตรฐาน OBD2 (รอบ ความเร็ว น้ำ คันเร่ง MAP แบต) ส่วน injector duty ต้องตั้งคำสั่งเฉพาะรุ่นรถ ซึ่งเราเตรียมแนวทางไว้สำหรับ Honda บางรุ่น (FD, FB, GE, GK, FC) สอบถามรุ่นรถของคุณก่อนสั่งได้

ต้องใช้ ELM327 แบบไหน

ELM327 ที่เป็น WiFi หรือ Bluetooth LE (BLE) เกจเชื่อมต่อแบบไร้สายและจำอุปกรณ์ที่เลือกไว้ พอเปิดรถก็ต่อให้เองโดยอัตโนมัติ

ใส่รหัสผ่าน WiFi อย่างไร

ที่หน้า DEVICES กด SCAN แล้วแตะชื่อ WiFi ที่มีรหัส จะมีแป้นพิมพ์ขึ้นมาให้พิมพ์รหัสผ่านบนจอ (จอ 3.5") แล้วกด OK

อัพเดทเฟิร์มแวร์ยากไหม

ไม่ยาก ต่อ WiFi ที่มีอินเทอร์เน็ต ไปหน้า FLASH ดูเลขรุ่นบนเว็บ กด DOWNLOAD แล้ว FLASH (กดซ้ำเพื่อยืนยัน) หรือโหลดไฟล์จากหน้าดาวน์โหลดไปใส่การ์ด SD เองก็ได้

ไฟล์ล็อกเปิดดูได้อย่างไร

ถอดการ์ด SD ไปเสียบพีซี แล้วเปิดไฟล์ .rlog ด้วยโปรแกรม R0CKY LogViewer ไฟล์จะแสดงข้อมูลได้เมื่อมีกุญแจของร้าน จึงเปิดได้เฉพาะร้านที่ลงกุญแจให้บอร์ดนั้น

ต่างกันอย่างไรระหว่างจอ 2.8" กับ 3.5"

จอ 3.5" เป็นจอ IPS ใหญ่กว่า ภาพคมกว่า และชิป ESP32-S3 แรงกว่า มีแป้นพิมพ์กรอกรหัส WiFi บนจอ ส่วนจอ 2.8" เล็กกะทัดรัดกว่า เหมาะกับช่องติดตั้งที่จำกัด
