เลือกไฟล์ให้ตรงกับขนาดจอ บอร์ด และรุ่นเกจ (OBD2 หรือ MaxxECU) แล้วใส่ในการ์ด microSD หรือให้เกจโหลดเองจากหน้า SYSTEM > FIRMWARE เลขรุ่นด้านล่างดึงจากเซิร์ฟเวอร์อัพเดทโดยตรง

7นิ้ว

เกจจอ 7" MaxxECU

Waveshare ESP32-P4 · 1024 × 600 · CAN bus

…รุ่นล่าสุด

ดาวน์โหลด maxx7.bin
  • ไฟล์maxx7-….bin
  • ติดตั้งผ่าน Wi-Fi

เกจจอ 7" ไม่ใช้การ์ด SD อัพเดทผ่าน Wi-Fi ที่หน้า SETTINGS > FIRMWARE ไฟล์นี้สำหรับร้านที่แฟลชผ่าน USB

ใช้ไฟล์ให้ตรงรุ่นจอและรุ่นเกจ — แต่ละเกจหาไฟล์ชื่อของตัวเองในการ์ด SD และโหลดจากเว็บเฉพาะไฟล์ของตัวเอง ไฟล์ของรุ่นอื่นจึงไม่ถูกติดตั้ง จอ 3.5" มีสองบอร์ด ดูชื่อบอร์ดที่ด้านหลังจอ (ES3C35P หรือ JC3248W535) แล้วเลือกการ์ดให้ตรง เกจ OBD2 กับเกจ MaxxECU ก็ใช้ไฟล์แทนกันไม่ได้

วิธีติดตั้ง

แฟลชจากการ์ด SD

  1. ดาวน์โหลดไฟล์ของจอและรุ่นเกจที่ใช้อยู่จากด้านบน (จอ 7" ไม่ใช้การ์ด SD ใช้วิธีด้านขวา)
  2. คัดลอกไฟล์ไปที่รากการ์ด microSD
  3. เสียบการ์ดเข้าเกจ เปิดเครื่อง ปัดไปหน้า SYSTEM แล้วแตะ FIRMWARE
  4. แถว On SD card ขึ้นเลขรุ่น กด INSTALL แล้วกด INSTALL NOW ในหน้ายืนยัน อย่าปิดไฟจนกว่าจะรีบูต

ให้เกจโหลดเอง

  1. ต่อ WiFi ที่มีอินเทอร์เน็ตจากหน้า CONNECTION (เลือกเครือข่าย ใส่รหัสผ่าน แล้วกด Connect)
  2. ไปที่ SYSTEM > FIRMWARE (จอ 7": SETTINGS > FIRMWARE) รอให้แถว Available online ขึ้นเลขรุ่น
  3. กด DOWNLOAD เกจจะเก็บไฟล์ลงการ์ด SD (ต้องมีการ์ดใส่อยู่ จอ 7" เขียนลงเครื่องเลยไม่ต้องใช้การ์ด)
  4. กด INSTALL แล้วกด INSTALL NOW ในหน้ายืนยัน อย่าปิดไฟจนกว่าจะรีบูต
